## 🎯 Project Objective
The objective of this project is to analyze financial transaction data and create an interactive Power BI dashboard that provides insights into:
- Financial transaction performance
- Transaction amounts and counts
- Average transaction value
- Fees and taxes
- Transaction status
- Customer segments
- Transaction types
- Gender-wise tax analysis
- State-wise tax analysis
- Monthly financial trends

## 📈 Dashboard Features
### 1. Overview Analysis
The dashboard provides a quick overview of:
- Total Amount
- Total Transactions
- Average Transaction Value
- Total Fees
- Total Tax
- Year-over-year performance comparison
### 2. Transaction Analysis
The transaction page provides detailed information about:
- Transaction ID
- Transaction Date
- Customer Name
- Transaction Type
- Transaction Status
- Gender
- Customer Segment
- State
- Total Amount
- Total Fees
- Total Tax
### 3. Financial Analysis
The dashboard includes:
- Monthly Total Tax Trend
- Tax by Transaction Status
- Tax by Customer Segment
- State-wise Tax
- Transaction Type Analysis
- Gender-wise Tax
### 4. Interactive Filters
Users can interact with the dashboard using filters such as:
- Year
- Dynamic Metric
- Occupation
- Category
